# Archived analysis documents

These reports were written on 2026-07-11 (and `quality_scorecard.md` on
2026-07-24) against an earlier state of the codebase. They are kept for
provenance only.

**They are stale and several of their claims are no longer true.** They
describe `scripts/test_*.py` files that have been renamed to `probe_*.py`,
an `expand_query()` function that has been removed, an eagerly-loaded
vectorstore that is now lazy, and a Groq optimizer model that has since been
decommissioned.

Do not treat anything here as a current description of the system. For that,
see `README.md`, `ARCHITECTURE.md`, and the test suite.

Safe to delete.
