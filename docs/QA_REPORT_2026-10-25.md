All chunk text, ordering and page numbers remain unchanged. The ingester now preserves table titles across flat continuation headings and offers a backed-up, idempotent --repair-headings operation.
- Prevented checklists and mechanism/pathophysiology questions being narrowed to five passages by an incorrect simple classification. Preserved hyphenated named criteria when optimizer expansion removed their lookup key. - Supplied the verifier with the original question and the same additional evidence as the draft, including retry verification. The verifier is instructed to retain the requested scope and restore explicitly supported checklist items that the draft omitted.
- Removed embedded extraction page markers before authoritative citations are appended. Reject invented pages, mismatched chunk IDs and malformed citations. Accept validated shorthand grouped references such as [p:1063, 1231], which previously caused a correct page group to be refused.
- Normalize opening context declinations to the required refusal string with Low confidence and no misleading images. Explicit context gaps anywhere force Low confidence and prevent caching. Missing-index answers are capped at Low and are not cached. Cache schema v6 retires stale earlier labels; the old cache was preserved before retirement.
- Treat a model-specific subscription-tier denial as deployment unavailability so later fallback deployments are tried. Invalid credentials still receive the existing non-fallback AUTH handling. Independent verification and request budgets remain enabled.
- Escaped model answer HTML at the actual display call site. The old renderer self-check escaped its input, while the real UI did not. Added a regression covering the real display function and exercised an inert synthetic HTML-injection payload in the browser.
- Added ordered/nested list and italic rendering, spacing between citation chips, readable validation errors, and handling for invalid successful response bodies. Browser error states recover with the submit button enabled.
- Fixed the evaluation judge's truncated JSON: independent output budget, thinking disabled through the existing model-dependent helper, JSON response format, retries for temporary service failures, and authenticated cache clearing. A failed judge can no longer be hidden by averaging only successful scores.
