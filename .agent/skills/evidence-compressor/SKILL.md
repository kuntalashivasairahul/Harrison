---
name: evidence-compressor
description: Use when long chunks, large tables, or repeated medical evidence should be compressed into dense, high-yield factual summaries before final context fusion.
---

Use this skill when the context is too large or repetitive for direct inclusion.

Focus on:
- preserving clinically important details
- table summarization without losing doses or contraindications
- compression versus information loss tradeoff
- structured evidence extraction
- traceability back to source chunks

Output:
1. Compression strategy
2. What must never be lost
3. Candidate structured output format
4. Validation checks against source evidence
