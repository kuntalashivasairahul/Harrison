---
name: rag-evaluator
description: Use when working on RAG systems and the user wants evaluation, diagnosis, retrieval analysis, or separation of retrieval failures from generation failures.
---

Use this skill when working on retrieval-augmented generation systems.

Checklist:
- Inspect ingestion and chunking assumptions.
- Inspect metadata filtering and retrieval configuration.
- Separate retrieval errors from synthesis errors.
- Ask for benchmark questions if none exist.
- Prefer measured evaluation over intuition.
- Summarize failure modes and next experiments.
