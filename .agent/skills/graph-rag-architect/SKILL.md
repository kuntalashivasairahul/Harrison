Use this skill when standard vector retrieval is not enough for relationship-heavy questions.

Focus on:
- graph schema design
- node and edge definitions
- graph construction pipeline
- retrieval over graph plus vector store
- multi-hop reasoning needs
- evaluation of graph usefulness versus added complexity

Output:
1. Proposed graph layer
2. Integration with current RAG pipeline
3. Data model and traversal strategy
4. Risks, cost, and validation plan
