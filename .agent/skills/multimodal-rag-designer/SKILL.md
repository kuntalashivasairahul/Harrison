---
name: multimodal-rag-designer
description: Use when designing or improving multimodal RAG systems involving images, visual embeddings, image-text retrieval, or visual evidence fusion.
---

Use this skill when image content should be a first-class part of retrieval rather than a static attachment.

Focus on:
- image embedding strategy
- text-image alignment
- multimodal indexing design
- retrieval fusion between visual and textual evidence
- latency and storage tradeoffs
- evaluation of image retrieval quality

Output:
1. Multimodal architecture recommendation
2. Required pipeline changes
3. Risks and failure modes
4. Validation strategy
