---
name: retrieval-planner
description: Use when a query should be decomposed into multiple retrieval steps, sub-questions, or staged evidence gathering before synthesis.
---

Use this skill for complex questions that mix mechanism, diagnosis, treatment, dosage, or multiple evidence types.

Focus on:
- query decomposition
- staged retrieval
- sub-question design
- evidence merging strategy
- avoiding context bloat
- preserving source attribution

Output:
1. Retrieval plan
2. Sub-queries to run
3. Evidence fusion strategy
4. Expected failure points
