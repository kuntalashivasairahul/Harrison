---
name: ui-validator
description: Use when reviewing frontend or portfolio UI for spacing, hierarchy, responsiveness, readability, accessibility, and interaction quality.
---

Use this skill for UI review, especially in portfolio or product-facing frontend work.

Check for:
- layout consistency
- spacing rhythm
- typography hierarchy
- contrast and readability
- responsive behavior
- overflow or clipping
- weak CTA emphasis
- accessibility issues in forms and navigation

Output:
1. Critical UI issues
2. Important polish issues
3. Quick wins with high visual impact
4. Suggested final QA checklist
