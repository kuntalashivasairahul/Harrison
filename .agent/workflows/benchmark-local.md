---
description: Design or run a local-first evaluation and benchmarking workflow for the current RAG system
---

When invoked:
1. Identify the current benchmark setup.
2. Separate cloud-dependent steps from local steps.
3. Propose or run a local evaluation path using available local models and tools.
4. Report:
   - metrics collected
   - failure modes
   - runtime and cost tradeoffs
   - recommended benchmark expansion
5. Prefer reproducible, rate-limit-resistant evaluation.
