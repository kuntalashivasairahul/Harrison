---
description: Convert one roadmap item into a buildable technical feature specification
---

When invoked:
1. Restate the target feature.
2. Define:
   - user value
   - technical objective
   - scope
   - non-goals
   - API or interface changes
   - storage or indexing changes
   - evaluation plan
   - rollback plan
3. Keep the spec concrete enough for implementation.
4. Call out unknowns explicitly.
