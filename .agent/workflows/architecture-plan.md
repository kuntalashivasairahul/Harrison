---
description: Design a phased architecture plan for a large feature or multi-stage RAG upgrade
---

When invoked:
1. Restate the feature or roadmap item clearly.
2. Break it into implementation phases.
3. For each phase, define:
   - goal
   - key components
   - files or modules likely to change
   - dependencies
   - risks
   - tests and evaluation strategy
4. Prioritize by implementation risk, expected impact, and ease of verification.
5. Do not jump into coding until the phase plan is clear.
