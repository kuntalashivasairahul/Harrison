description: Reproduce a bug, isolate the root cause, and propose the smallest safe fix
---

When invoked:
1. Understand the bug from logs, tests, or description.
2. Reproduce it if possible.
3. Isolate the likely root cause.
4. Propose the smallest safe fix.
5. After fixing, summarize:
   - root cause
   - files changed
   - how it was verified
