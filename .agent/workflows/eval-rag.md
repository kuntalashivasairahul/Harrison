---
description: Evaluate a RAG pipeline by separating retrieval issues from generation issues
---

When invoked:
1. Inspect the current RAG pipeline:
   - ingestion
   - chunking
   - embeddings
   - retrieval
   - prompt assembly
   - response generation
2. Separate retrieval failures from generation failures.
3. Identify likely causes of bad results.
4. Suggest the top 3 improvements with the highest expected impact.
5. Prefer measured evaluation over intuition.
