What it will not do

The useful part of a reference tool is knowing where it stops.

It refuses rather than guesses

The corpus has gaps. When the retrieved text does not support an answer, you get this — verbatim, unsoftened, with no invented citation to dress it up.

Insufficient information in the provided context.

It tells you how sure it is

Every answer carries a confidence grade derived from retrieval quality — never asserted by the model about itself.
